# MLBB Boost

Публичный сайт: https://boostmlbb.ru. Публикация — GitHub Pages, ветка `main`, корень репозитория. `.nojekyll` сохраняет статические Markdown и `.well-known` ресурсы.

## Проверка и локальный просмотр

```sh
npm ci
npm run site:prepare
npm run dev
```

`serve.json` сохраняет `.html` адреса и параметры заказа, как на production. `site:prepare` собирает обе языковые версии и новости, проверяет SEO и ссылки, затем проверяет калькулятор и необязательный Markdown Worker.

## Редактирование

- Русские страницы в корне — источники шаблонов. `en/*.html`, `guides`, `markdown`, карты сайта, `llms*` и агрегаты отзывов генерируются. Не правьте английские копии напрямую.
- `content/seo-pages.json` — метаданные, дополнительные блоки и двуязычные руководства. `content/seo-translations.json` дополняет словари. Новые переводы должны давать пустой `content/translation-gaps.json`.
- `npm run site:sync-data` получает и проверяет публичные цены и отзывы. При ошибке API сохранённый снимок остаётся целым. Затем выполните `npm run site:prepare`.
- `npm run site:assets` обновляет локальные иконки, миниатюры и социальные изображения. Это отдельная ручная операция: шрифты для социальных карточек могут отличаться между ОС.
- Новости: `content/news/*.json` и существующий `scripts/news-pipeline.mjs`. Проверка требует источники, согласованные RU/EN материалы и правильные изображения.

GitHub Actions проверяет каждый PR и `main`, включая повторяемость сборки. Ежедневное обновление получает публичные данные, сохраняет реальные изменения и явно запрашивает сборку Pages: коммиты с `GITHUB_TOKEN` сами её не запускают.

## Ограничения хостинга

GitHub Pages не применяет `.htaccess`, не запускает Cloudflare Worker и не предоставляет произвольные HTTP-заголовки. Каждая основная HTML-страница содержит ссылку на настоящую статическую Markdown-копию. `Accept: text/markdown` на действующем хостинге не включает согласование формата.

`src/index.js` — отдельно тестируемый необязательный Worker. `wrangler.toml` содержит незаполненную конфигурацию; его нельзя считать развёрнутым. Для него потребуется отдельная настройка маршрута и зоны.

Индексацию, поисковые позиции и полевые Core Web Vitals отслеживайте в Google Search Console и Яндекс Вебмастере. Код и автоматические тесты не заменяют эти данные. Результаты аудита: [docs/SEO-UPGRADE.md](docs/SEO-UPGRADE.md).
