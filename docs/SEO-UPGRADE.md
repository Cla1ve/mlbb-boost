# SEO и качество сайта — 5 октября 2026

Исправления выполнены для https://boostmlbb.ru и GitHub Pages. Цель — сделать содержимое доступным поисковикам и AI, устранить несогласованные сведения и сократить загрузку. Первое место в выдаче не является гарантируемым результатом технических работ.

## Главные изменения

1. Вместо переводов только через JavaScript и `?lang=en` добавлены самостоятельные английские HTML-страницы. Для 44 HTML проверены self-canonical, reciprocal RU/EN/x-default, языки, основные заголовки и JSON-LD. В sitemap 42 индексируемых URL; две 404-страницы имеют `noindex`.
2. Обновлены метаданные, реальные социальные изображения и структура Organization/WebSite/WebPage/Service/Breadcrumb/Article. Удалены выдуманный отзыв и саморекомендующая разметка AggregateRating. ОГРНИП `326690000001430` предоставлен владельцем; прежний 20-значный номер исключён.
3. Статические цены и fallback получены из публичного API. На момент проверки базовые цены обычного буста: Воин/Элита 55 ₽, Мастер/ГМ 80 ₽, Эпик 95 ₽, Легенда 105 ₽, калибровка 180 ₽ за победу, Мифик 125 ₽, Честь 135 ₽, Слава 145 ₽, Бессмертный 165 ₽ за звезду. Стоимость маршрута и право на скидку подтверждаются перед оплатой.
4. Полных опубликованных отзывов — 1151; средняя оценка округлена до 5.0/5, 99% оценок — 4 или 5. Это агрегат публичной коллекции после фильтра неполных записей, а не независимая сертификация. На главной больше не загружается вся коллекция ради трёх чисел. Ссылки на оригиналы доступны статически.
5. Добавлены два содержательных руководства на двух языках: калибровка Мифика и игра в пати. Основные страницы объясняют выбор формата, порядок заказа, единицы цены и роль сервиса. Убраны абсолютные обещания безопасности, неподтверждённые сроки и профессиональные статусы. Оценка винрейта из API обозначена как оценка.
6. Для AI добавлены доступные `llms.txt`, `llms-full.txt`, статические Markdown-копии и API catalog с расширением JSON. Агентские инструкции согласованы с реальным хостингом, ценами и отзывами; контрольные SHA соответствуют опубликованным файлам.
7. Hero заменён на адаптивный WebP: около 40/69 КБ вместо 398 КБ. Локальные SVG-иконки заменили загрузку Font Awesome CSS и двух шрифтов. Миниатюры рангов соответствуют отображаемому размеру. Неинтерактивные страницы используют небольшой переключатель языка вместо больших словарей.
8. FAQ работает через native details/summary; этапы Rising доступны клавиатурой. Добавлены состояния выбора, объявление результата расчёта и ссылка пропуска меню. Контент и мобильное меню доступны без JavaScript. Декоративные частицы исключены из загрузки. Стиль бренда сохранён, поясняющие блоки адаптированы для телефона.
9. Добавлены проверка сайта, калькулятора и Worker, CI для PR/main и обновление публичных данных с безопасным сохранением снимка. Сборка повторяема; старые сведения не возвращаются после повторного запуска.

## Проверки

`npm run site:prepare` проверяет сборку, все локальные ссылки в 44 страницах, 42 sitemap URL, статические тарифы, языковые связи, перевод и контрольные суммы. Тесты калькулятора покрывают вход в калибровку, цель с нулём звёзд, сброс старых полей и граничные цели. Worker сохраняет HTTP-ошибки, заголовки кэша и заголовок статьи; не отдаёт Markdown при `q=0` или большем предпочтении HTML.

Проверены реальные API-расчёт, переключение языка с `type`/hash, мобильное меню, FAQ, Rising, отсутствие горизонтального переполнения на 320–1440 px и отображение без JavaScript. Платёж или новый заказ не отправлялись. Автоматический axe не обнаружил нарушений в проверенных RU/EN сценариях; это не полная сертификация доступности, контраст градиентов требует ручной оценки.

Исходная публичная главная: около 1.52 МБ холодной загрузки и LCP 6.41 с при 1.6 Mbps/150 ms/CPU×4. Промежуточная локальная сборка: 406 КБ и LCP 2.78 с в том же профиле. Это лабораторное сравнение разных серверов; результаты production фиксируются отдельно после публикации. Не выдавать их за полевые Core Web Vitals или оценку Lighthouse.

## Что требует данных после публикации

- Отправить https://boostmlbb.ru/sitemap.xml в Google Search Console и Яндекс Вебмастер, проверить выбранные canonical и индексирование RU/EN. Верификационный метатег Google сохранён.
- По данным запросов и конверсий выбрать следующие материалы. Не создавать серии похожих страниц под перестановки ключевых слов.
- Подтверждать опыт исполнителей, сроки, правила скидок и качество сервиса реальными данными. Репутация и упоминания независимых источников формируются за пределами кода.
- Отслеживать полевые LCP/INP/CLS и ошибки API. Третьесторонние аналитические скрипты сохранены; их загрузка остаётся значительной частью оставшегося трафика.
- При необходимости управляемых cache/security/Link/Vary HTTP-заголовков перейти на хостинг с соответствующей поддержкой или отдельно настроить Worker. Не считать Apache-конфигурацию работающей на GitHub Pages.

- [Google: review snippets](https://developers.google.com/search/docs/appearance/structured-data/review-snippet): ограничения саморекомендующих рейтингов организации.
- [Яндекс: Sitemap](https://yandex.ru/support/webmaster/en/indexing-options/sitemap) и [canonical](https://yandex.ru/support/webmaster/en/robot-workings/canonical?lang=en): карта сайта и канонические адреса.

- Вспомогательная методика: [claude-seo](https://github.com/AgriciDaniel/claude-seo). Выводы сверены с исходниками, действующим API и официальными документами; эвристики skill не выданы за требования поисковиков.
